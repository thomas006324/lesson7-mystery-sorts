# Lesson 7: Identify the Mystery Sorts (IT 145-5)

Three compiled sorting programs (sort1, sort2, sort3) were timed on 5,000, 10,000 and 50,000 numbers, each sorted, reversed and random: 27 runs in total.

- **timings.md**: the full timing table
- **Mystery_Sorts_Thomas_Jara.pdf**: the write-up identifying each program

Result: sort1 is bubble sort, sort2 is merge sort, sort3 is selection sort.
